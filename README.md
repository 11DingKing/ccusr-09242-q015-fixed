# 微专业就业成效追踪系统

维护毕业生、学院、微专业、就业去向、企业跟进和预警记录，支持按届次与组织维度追踪就业成效并保留分析依据。

## 运行约定

服务端代码位于 `app` 目录，默认使用项目目录中的 SQLite 文件。配置通过环境变量提供，导入演示数据前请确认数据库位置可写。

## 测试

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

## 编译检查

在项目根目录执行：

```bash
python3 -m compileall -q app tests
```

## 启动服务

准备依赖后可执行 `uvicorn main:app --host 127.0.0.1 --port 8000`，根路径与 `/health` 返回服务状态，接口文档位于 `/docs`。

## 访问控制边界

所有 `/api/v1` 业务接口统一要求调用方身份（由网关注入请求头）：

| 请求头 | 说明 |
| --- | --- |
| `X-Auth-Role` | `school`（校级，全量能力）或 `college`（学院，仅本学院） |
| `X-Auth-College-Id` | 学院角色必填，绑定所属学院ID |

强制规则：

- 学院角色在统计对比、组合筛选（学院/微专业/届次）、年度趋势、报告、预警、归因、
  毕业生与回访明细上一律按所属学院收口；“未修读微专业”等对照组同样限定在本学院。
- 显式传入越权的 `college_id` / `micro_major_id` / 路径资源ID时返回 **403**
  （`{"detail": "无权访问该范围的数据"}`），不返回容易被误读为“没有数据”的空结果；
  403 响应不含任何统计数字。
- 写操作（建档、修改、删除、预警检测、基准线维护）仅限校级角色。
- 越权事件写入安全审计，仅记录角色、路径、资源类型/ID与原因码，不记录响应体或敏感数字。
- 报告链接（`/statistics/reports/link`）带 HMAC 签名与有效期，每次使用都按调用方
  **当前**角色与学院范围重新校验；角色或范围变化、链接过期/被篡改时一律 403，
  不会回放旧授权下的缓存内容。所有业务响应附带 `Cache-Control: no-store`。

验收测试见 `tests/test_access_control.py`，覆盖校级/学院角色在学院、微专业、
年度查询上的差异，以及越权请求在响应与审计记录中均不泄露敏感数字。
