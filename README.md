# 微专业就业成效追踪系统

维护毕业生、学院、微专业、就业去向、企业跟进和预警记录，支持按届次与组织维度追踪就业成效并保留分析依据。

## 运行约定

服务端代码位于 `app` 目录，默认使用项目目录中的 SQLite 文件。配置通过环境变量提供，导入演示数据前请确认数据库位置可写。

## 访问控制

所有业务接口都要求调用方身份，通过请求头 `X-Access-Token` 携带访问令牌，未提供或令牌无效返回 401。

- **校级管理员**：保留全量能力，可查询任意学院、微专业与届次的统计、预警和明细，并负责账号与授权管理。
- **学院用户**：只能访问被授权学院范围内的数据。统计、预警、明细等接口会自动按授权范围过滤；显式传入范围外的学院、微专业等参数时返回 403 明确拒绝，而不是返回容易误解的空数据。

授权范围保存在服务端（`user_college_grants` 表），校级管理员可通过 `PUT /api/v1/users/{user_id}/grants` 调整，调整后立即生效。

演示数据初始化的账号（见 `scripts/init_data.py`）：

| 账号 | 令牌 | 角色 |
| --- | --- | --- |
| school_admin | `school-admin-token` | 校级管理员 |
| college_cs 等 | `college-cs-token` 等 | 学院用户（授权对应学院） |

## 报告分享链接

`POST /api/v1/share-links` 可生成学院、微专业或届次的复核报告链接。链接只保存报告定义，不缓存内容；每次经 `GET /api/v1/share-links/{token}` 访问时都会重新校验：

1. 链接未被撤销；
2. 创建者当前的授权范围仍覆盖报告参数；
3. 访问者当前的授权范围也覆盖报告参数。

任一条件不满足即返回 403，报告内容在校验通过后实时计算。权限收窄或链接撤销后，旧链接立即失效。

## 访问审计

受保护接口的调用都会写入审计记录（`audit_logs` 表），包括允许与拒绝的判定。审计只记录调用方、接口、请求参数与判定原因，不记录统计数值等敏感内容。校级管理员可通过 `GET /api/v1/audit-logs` 查询。

## 测试

在项目根目录执行：

```bash
python3 -m unittest discover -s tests -v
```

## 编译检查

在项目根目录执行：

```bash
python3 -m compileall -q app tests
```

## 启动服务

准备依赖后可执行 `uvicorn main:app --host 127.0.0.1 --port 8000`，根路径与 `/health` 返回服务状态，接口文档位于 `/docs`。
